# UBCx: How to Code — Complex Data

Notes and solutions for **UBCx *How to Code: Complex Data*** (edX), the second course in UBC's *Systematic Program Design* series. It is taught in Racket (Intermediate Student Language) using the *How to Design Programs* recipe.

## Modules

| # | Module | Focus | Folder |
|---|---|---|---|
| 1 | Mutual reference | Designing with mutually referential data (e.g. file systems) | `mutual_reference/` |
| 2 | Two one-of types | Cross-product templates for functions that consume two complex inputs | `two_of_one_type/` |
| 3 | Local | Using `local` expressions for encapsulation and efficiency | `local/` |
| 4 | Abstraction | Generalizing functions; parameterization, closures, built-in abstract functions | `abstraction/` |
| 5 | Generative recursion | Generative recursion (fractals) | `generative_recursion/` |
| 6 | Search | Search problems built on generative recursion (e.g. Sudoku) | — |
| 7 | Accumulators | When and how to use context-preserving and result accumulators | — |
| 8 | Graphs | Recognizing graph-shaped data and writing functions over it | — |

`practice_problems/` contains extra exercises: family trees, image organizers, merge, zip and concat.

## Running

Open any `.rkt` file in [DrRacket](https://racket-lang.org/) with the language set to the appropriate *How to Design Programs* student language.
